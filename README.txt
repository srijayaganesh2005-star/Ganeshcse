VELOOP Rewards multi-page HTML/CSS/JS demo.
Run: extract ZIP, open the folder in VS Code, then start Live Server from index.html.
Pages: Home (index.html), About (about.html), Dashboard (dashboard.html), Quiz (quiz.html), Exchange Center (exchange-center.html).
All navigation links open real pages. Demo balances/history persist between these pages using browser localStorage. The quiz, daily spin and exchanges are frontend demo interactions; this package is NOT connected to your deployed backend or database. Data is browser-local and can be cleared/reset.
